# Build Assets

## App Icon

Platziere hier dein App-Icon:
- **Dateiname**: `icon.ico`
- **Format**: ICO-Format (Windows Icon)
- **Größe**: 256x256 Pixel empfohlen

Du kannst ein PNG in ein ICO konvertieren mit Online-Tools wie:
- https://convertio.co/de/png-ico/
- https://icoconvert.com/

Wenn kein Icon vorhanden ist, wird ein Standard-Electron-Icon verwendet.
